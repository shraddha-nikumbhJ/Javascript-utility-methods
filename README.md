#React App

A React + Typescript application created from scratch with Webpack as bundler. Current application follows frontend architecture following-
  1. React 19
  2. Typescript
  3. Webpack
  4. Babel
  5. EsLint
  6. Prettier
  7. React Router
  8. SCSS

#Features Implemented are-
Product List Page including Performance Optimization techniques-

•	useCallback 
•	React.memo 
•	Lazy loading
•	Suspense 
•	Code splitting 
•	Virtualization 
•	Error Boundaries
